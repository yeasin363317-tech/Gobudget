Offline-first by architecture.

Core records are stored locally in device storage. No mandatory login or cloud database is used for everyday tracking.

Transparent limitations.

Local storage is not automatically encrypted or backed up to the cloud. Export a JSON backup before clearing app data or uninstalling.

Privacy & offline

Your financial life, on your device.

GoBudget uses local device storage for core financial records. Internet is not required for everyday transaction, wallet, budget or goal operations.

Where is data stored?In the app's local storage on this Android device.
Is cloud sync included?No. There is no automatic cloud synchronization in this release.
What about encryption?Do not treat local storage as automatically encrypted.
How do I back up?Use GoBudget's JSON export and keep the file somewhere safe.
